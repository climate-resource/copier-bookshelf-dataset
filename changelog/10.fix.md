Dropped the dependency on the private `climate-resource/github-actions` repository.

GitHub does not let a public repository resolve actions or reusable workflows that live in a private repository, whatever the access policy says.
This repository is public, so every reference to the shared actions failed with `Unable to resolve action`.

- The bump workflow now inlines the `uv version` bump, the towncrier build, the tag and the draft release, in this repository and in the template.
- `actions/record-bundle` calls `astral-sh/setup-uv` directly. This also repairs the composite for the public feedstocks that consume it.
- A contract test now fails if any workflow or action reaches for the private repository again.
