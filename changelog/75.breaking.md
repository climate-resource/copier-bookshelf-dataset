Removed the `sdk-version` input of the reusable feedstock CI workflow and the `bookshelf_sdk_version` answer.
A feedstock must run `copier update` and then `uv lock`, so `uv.lock` on `main` resolves `bookshelf` within `>=1.0,<2`.
The preview job fails if `uv.lock` on `main` has no `bookshelf` entry.
