Records and publishes every version the recipe declares.
The reusable CI and publish workflows loop over `books:` rather than taking a version,
so the recipe stays the one place a version is written down.
Publishing an unchanged book is idempotent, so a version that has not moved keeps its edition.
Pass a `version` input to either workflow to narrow the run to one book.

Derives the CI input cache key from the recipe rather than from the build file,
because the digests a feedstock declares now live in `bookshelf.yaml`.
