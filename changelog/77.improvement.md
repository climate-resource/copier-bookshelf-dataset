Rendered feedstocks now pin Python 3.14 and support 3.13 onwards, following SPEC 0.
The reusable feedstock workflow and `record-bundle` action default to 3.14.

The rendered `renovate.json` now extends the shared Climate Resource Renovate preset.
Updates arrive on Monday mornings after a 3-day wait, with non-major updates grouped into one pull request.
Template releases still open their own `template-update` pull request as soon as they ship.
A feedstock with a hand-edited `renovate.json` should take the template's version when `copier update` conflicts.
