Cut the generated `renovate.json` down to the two rules that keep Renovate away from the Copier owned pins,
plus the `copier` and `pre-commit` managers.
Everything else was a preference the file restated, so a feedstock now takes it from `config:best-practices`.
Lock file maintenance survives the trim, because that preset already runs it early on a Monday.

What a feedstock loses is the local scheduling and labelling:
- Updates now open as soon as a release lands, rather than waiting for a Monday window.
  Grouping falls back to what the preset supplies, so expect more, smaller pull requests.
- Python updates lose their three day soak, because the preset only ages npm releases.
- Pull requests arrive without the `dependencies` and `template-update` labels,
  and security pull requests without the `security` label.
