# PRIMAP-hist 2024

Historical national emissions, hyphenated and numbered.

This repository is a feedstock that turns upstream data into books on the
[Bookshelf](https://github.com/climate-resource/bookshelf).
`bookshelf.yaml` is the recipe and `build.py` builds one version of it.

Building, previewing and publishing are documented in
[copier-bookshelf-dataset](https://github.com/climate-resource/copier-bookshelf-dataset#working-on-a-feedstock).
